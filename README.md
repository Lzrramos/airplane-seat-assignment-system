# Airplane Seat Assignment System (Java)

## Overview
This project is a console-based airplane seat assignment system built in Java. It demonstrates object-oriented programming principles by modeling an airplane seating structure using a 2D array and managing passengers through a menu-driven interface.

Users can add, find, and remove passengers, as well as view all occupied and empty seats in the airplane.

---

## Features
- Assign passengers to specific seats
- Remove passengers from seats
- Search for passengers by seat location
- Display all occupied seats with passenger details
- Display all empty seats
- Validate user input safely
- Menu-driven console interface
- Dynamic airplane size based on user input

## How It Works
1. The user enters the number of rows for the airplane
2. The system initializes a 2D seating chart (rows × 4 columns)
3. Users interact with a menu to manage passengers:
   - Add passenger to a seat
   - Remove passenger from a seat
   - Search for a passenger
   - View all passengers
   - View empty seats
4. The program runs continuously until the user chooses to exit
